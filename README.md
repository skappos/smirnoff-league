# Smirnoff League

Fantasy football league HQ for Sleeper league `1394061072742227968`.

## Ice rules
- Any starter who finishes a fantasy week with **0.00 or negative points** earns the manager one Ice.
- The **lowest-scoring team of the week** earns one additional Ice.
- Ices stack.
- Ices are due the following **Sunday at 1:00 PM ET**.
- League members upload their Ice video and claimed chug time; the video does not require commissioner approval, but the **chug time must be commissioner-verified** before it counts on the leaderboard.

## Current version
This is the initial static prototype. It reads public league metadata from Sleeper in the browser and contains the Week 1 seed data. Submission data is currently browser-local; persistent shared uploads/admin authentication require a backend/storage service.
